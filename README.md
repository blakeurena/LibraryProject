# LibraryProject

A simple **Library Management** application for tracking a collection of books and basic library operations (adding/removing books, searching, and managing availability).

## Features

- Add new books to the library catalog
- View a list of all books
- Search books (e.g., by title, author, or ID)
- Update book details
- Check out / return books (availability tracking)
- Delete books from the catalog
